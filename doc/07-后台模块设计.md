# 07 后台模块设计

## 1. 模块职责

`novel-admin` 负责平台运营、内容管理与系统管理。

## 2. 主要功能

- 小说管理
- 分类管理
- 章节管理
- 评论管理
- 用户管理
- 作家管理
- 支付管理
- 新闻管理
- 友情链接管理
- 网站配置管理
- 统计管理
- 系统用户、角色、菜单、字典管理
- 代码生成辅助

## 3. 主要入口

- 启动类：`AdminApplication`
- 核心控制器：
  - `BookController`
  - `BookContentController`
  - `BookIndexController`
  - `BookSettingController`
  - `AuthorController`
  - `UserController`
  - `NewsController`
  - `CategoryController`
  - `PayController`
  - `StatController`

## 4. 技术特征

- 使用 Spring Boot 2.7.x
- 使用 Thymeleaf 渲染后台页面
- 使用 Shiro 做权限控制
- 使用 ShardingSphere JDBC 访问数据源

## 5. 关键实现点

- 后台接口多为页面 CRUD 型接口
- 统计接口作为运营报表入口
- `sys_*` 表支撑后台基础系统能力
- 存在代码生成辅助相关表结构
- `website_info` 已作为站点基础配置入口，后续继续承载模板名称、Logo、支付等站点级配置

## 6. `R-029` 相关设计补充

- 网站信息页除保存站点字段外，还负责维护前台模板名称
- 后台保存网站信息后，不再提示“重启 novel-front 后生效”
- 后台提供站点缓存清理入口，用于清理前台网站信息与模板相关缓存
- 后台在清理缓存失败时需要返回明确错误，避免运营误以为已经生效
