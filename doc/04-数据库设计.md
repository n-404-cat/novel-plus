## 3. 设计特征

- 章节内容存在独立内容表与分表
- 后台通过 ShardingSphere JDBC 访问分片配置
- SQL 交付同时覆盖初始化与升级场景

## 4. 后续维护要求

- 新增表或字段时，必须同步更新本文件
- 数据结构变更必须补增量 SQL
- 涉及分表策略调整时，必须同步更新部署与配置文档
