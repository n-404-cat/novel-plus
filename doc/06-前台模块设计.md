# 06 前台模块设计

## 1. 模块职责

`novel-front` 负责面向读者与作者的核心业务能力。

## 2. 主要功能

- 首页展示
- 分类、搜索、排行
- 小说详情、目录、阅读
- 用户注册登录
- 书架、阅读历史
- 评论互动
- 作家专区
- 支付充值
- AI 写作与生图

## 3. 主要入口

- 启动类：`FrontNovelApplication`
- 页面控制器：`controller/page/PageController.java`
- 业务控制器：
  - `BookController`
  - `UserController`
  - `AuthorController`
  - `NewsController`
  - `FriendLinkController`
  - `PayController`
  - `CacheController`

## 4. 页面组织

- 模板页面：`templates/<name>/html`（默认 `green`）
- 模板静态资源：`templates/<name>/static`
- 模块内模板与静态资源作为兜底：`novel-front/src/main/resources/templates`、`novel-front/src/main/resources/static`

## 5. 关键实现点

- 模板页面与 REST 接口并存
- 作者专区存在登录与作者身份校验
- 阅读内容依赖内容存储实现切换
- 支持模板资源复制与独立打包
- AI 能力通过 Spring AI 接入

## 6. 模板机制梳理

### 6.1 当前模板资产

当前仓库根目录下存在多套模板资源：

- `templates/green`
- `templates/orange`
- `templates/blue`
- `templates/dark`

每套模板基本包含：

- `html/`
- `static/`

### 6.2 当前开发环境实际生效方式

在当前 `dev` 配置下，前台优先使用仓库根目录下的模板目录：

- `templates/<name>/html`
- `templates/<name>/static`

也就是说：

- 开发模式下支持通过后台修改模板名即时切换
- 模块内模板与静态资源仍会作为兜底（模板目录缺失或资源不完整时可回退）

### 6.3 当前生产模式切换方式

在 `application-prod.yml` 中，前台通过以下配置读取模板：

- `spring.thymeleaf.prefix=file:${user.dir}/templates/${templates.name}/html/`
- `spring.web.resources.static-locations=file:${user.dir}/templates/${templates.name}/static/`

并且当前默认：

- `templates.name=green`

这说明：

- 生产模式支持通过 `templates.name` 切换模板目录
- 当前切换入口是配置文件，不是后台页面

### 6.4 当前后台是否支持切换

当前后台已支持维护前台模板名称，结论如下：

- 模板切换能力存在
- 后台在“网站信息”页维护模板名
- 前台请求期读取网站配置中的模板名，并按模板名动态定位模板 HTML 与静态资源

### 6.5 对 `R-029` 的影响

- `R-029 模板切换后台化` 需要补齐：
  - 模板配置存储位置
  - 后台配置页
  - 前台运行时读取逻辑
  - 模板资源存在性校验

### 6.6 当前实现进度

当前已完成：

- 网站信息后台页增加模板名配置入口
- 前台请求期动态读取网站配置中的模板名
- 对模板名增加受支持范围校验，不合法时回退到 `green`
- 模板 HTML 与模板静态资源都按当前模板名动态定位
- 网站信息已在请求期刷新到应用上下文，支持后台修改后直接生效

同时已补充：

- 后台站点缓存清理入口，用于清理前台网站信息相关缓存
- 模板静态资源禁用浏览器强缓存，避免切换后仍命中旧资源
