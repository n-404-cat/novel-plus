# 09 部署与运维手册

## 1. 构建命令

```bash
mvn clean package -DskipTests
```

## 2. 常见部署方式

参考当前仓库已有说明，典型流程如下：

```bash
cd /www/wwwroot/novel-plus
mvn clean package -DskipTests
systemctl restart novel-front
systemctl restart novel-admin
```

## 3. 配置位置

- 根配置：`config/shardingsphere-jdbc.yml`
- 前台：`novel-front/src/main/resources/application.yml`
- 后台：`novel-admin/src/main/resources/application.yml`
- 爬虫：`novel-crawl/src/main/resources/application.yml`

## 4. 数据库初始化

首次安装：

- 执行 `doc/sql/novel_plus.sql` 或
- 执行 `doc/sql/novel_plus_data.sql` 中对应 SQL

版本升级：

- 按日期顺序执行当前版本之后新增的增量 SQL

## 5. 当前运维关注点

- 后台依赖 `config/shardingsphere-jdbc.yml`
- 前台和爬虫采用独立服务端口
- 模板资源会在构建中复制
- 配置中存在示例敏感信息，正式环境必须替换
