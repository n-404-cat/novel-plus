# 05 接口设计

## 1. 说明

本文档记录当前系统的主要接口域，作为后续接口变更同步入口。

## 2. 前台接口

### 2.1 小说接口 `book/*`

主要能力：

- 首页推荐位
- 点击榜、新书榜、更新榜
- 分类查询
- 搜索分页
- 详情查询
- 排行查询
- 点击数更新
- 章节相关信息查询
- 评论、回复、点赞、点踩

### 2.2 用户接口 `user/*`

主要能力：

- 登录
- 注册
- Token 刷新
- 书架查询与维护
- 阅读历史查询与维护
- 用户反馈
- 用户信息查询与修改
- 密码修改
- 评论查询
- 章节购买

### 2.3 作者接口 `author/*`

主要能力：

- 笔名校验
- 作品分页查询
- 发书
- 更新书籍状态
- 发章节
- 查询章节内容
- 修改章节内容
- 更新封面
- 日/月收益
- AI 生图
- AI 扩写、缩写、续写、润色

### 2.4 其他前台接口

- `news/*`
- `friendLink/*`
- `cache/*`
- `pay/*`
- `file/*`

## 3. 后台接口

后台接口主要以 `/novel/*` 为前缀，覆盖：

- 小说管理
- 分类管理
- 章节管理
- 评论管理
- 用户管理
- 作家管理
- 新闻管理
- 友情链接管理
- 支付管理
- 统计管理
- 网站信息管理

其中网站信息管理已作为站点基础配置入口，后续承载：

- 站点名称
- 域名
- SEO 信息
- Logo
- 前台模板名称

当前与 `R-029` 直接相关的接口补充如下：

- 后台网站信息保存接口：`/novel/websiteInfo/update`
- 后台网站配置缓存清理接口：`/novel/websiteInfo/clearCache`
- 前台缓存刷新接口继续保留 `cache/refresh/*`，供后台转调或运维兜底使用

当前与 `R-030` 直接相关的接口现状如下：

- 前台发起支付宝支付：`POST /pay/aliPay`
- 前台支付宝异步通知：`/pay/aliPay/notify`
- 后台当前仅提供充值订单查询与详情，不提供支付渠道配置维护接口

`R-030` 后续需要补齐的接口方向：

- 后台支付配置查询接口
- 后台支付配置保存/更新接口
- 后台支付配置生效与缓存刷新接口
- 支付渠道启停与环境切换接口（沙箱/生产）

当前与 `R-032` 直接相关的后台接口现状如下：

- 已有小说管理接口：`/novel/book/*`
- 已有目录管理接口：`/novel/bookIndex/*`
- 已有正文管理接口：`/novel/bookContent/*`

`R-032` 后续需要补齐的接口方向：

- 小说审核详情聚合接口（一本小说下聚合基础信息、目录、正文）
- 小说审核操作接口（通过/驳回/发布）
- 审核意见记录查询接口
- 小说审核状态流转接口

## 4. 爬虫接口

主要能力：

- 新增爬虫源
- 爬虫源分页查询
- 获取爬虫源详情
- 规则测试
- 更新爬虫源
- 开启或关闭爬虫
- 新增单本采集任务
- 单本采集任务分页查询
- 删除采集任务
- 查询任务进度

## 5. 后续维护要求

- 新增、修改、删除接口时，必须同步更新本文件
- 接口参数或返回结构发生变化时，必须记录变更点
