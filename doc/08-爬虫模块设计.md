# 08 爬虫模块设计

## 1. 模块职责

`novel-crawl` 负责采集源配置、规则测试、采集任务管理和自动更新。

## 2. 主要功能

- 新增和修改采集源
- 启停采集源
- 采集源分页查询
- 规则测试
- 单本采集任务管理
- 采集任务进度查询
- 定时采集与更新
- 磁盘监控与邮件告警

## 3. 主要入口

- 启动类：`CrawlNovelApplication`
- 控制器：`CrawlController`

## 4. 关键接口

- `addCrawlSource`
- `listCrawlByPage`
- `getCrawlSource/{id}`
- `testParse`
- `updateCrawlSource`
- `openOrCloseCrawl`
- `addCrawlSingleTask`
- `listCrawlSingleTaskByPage`
- `delCrawlSingleTask/{id}`
- `getTaskProgress/{id}`

## 5. 关键实现点

- `testParse` 用于规则联调和页面结构匹配验证
- 模块启用了缓存与调度能力
- 自动更新线程数和采集间隔可配置
- 可扩展为多源采集治理中心
